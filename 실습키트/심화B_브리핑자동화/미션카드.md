# 심화 B — 소부장 브리핑 자동 조판: 생성하고, 지우고, 다시 생성한다

> 목표: 스크랩 엑셀 → 목차·기관별·기술별 자동 배치를 체험하고, "고치지 않고 재생성한다"는 갱신 원칙을 몸으로 확인한다.

## 0. 동봉된 실물부터 열어보기

`샘플산출_소부장브리핑_2606.html` — **여러분의 6월호 엑셀 그대로** 자동 조판한 결과입니다.
- 기사 85건 = 엑셀 85행 (전수 일치)
- 정책 16 · R&D 50 · 기업동향 19 — 6월호 Ⅲ장 공식 통계와 일치
- R&D 분야별: 첨단바이오 18(36%) · 인공지능 11(22%) · 반도체 10(20%) — 역시 일치

## 1. 직접 생성

6월 스크랩 엑셀을 이 폴더에 복사한 뒤 Claude Code에:

```
스크랩 엑셀의 '전체리스트' 시트를 읽고
① 분류·연번·제목 목차표
② 정책 기사를 기관별(과기정통부→산업부→중기부)로
③ R&D·기업동향 기사를 분야별(12대 기술 순서)로 배치한
브리핑 초안을 md와 HTML로 만들어줘.
연번과 건수 통계는 데이터에서 다시 세어 넣고, 원본 엑셀은 절대 수정하지 마.
```

## 2. 검증 습관 — 세는 것은 기계, 확인은 사람

```
엑셀 행수와 브리핑 기사 수가 일치하는지, 분류별 건수가 맞는지 세어서 보고해줘
```

## 3. 재생성 체험 (이 실습의 핵심)

1) 엑셀 **사본**에서 기사 1건을 삭제 (원본 보존!)
2) 같은 명령으로 재생성
3) 확인: 연번이 당겨졌는가? 목차·통계가 84건으로 바뀌었는가?

> 문서를 고치는 게 아니라 **엑셀을 고치고 다시 만든다** — 연번 밀림·목차 불일치·통계 누락이 구조적으로 사라집니다.

이 실습의 규칙(3단 배치 · 재계산 · 원본 불변 · 검증표)을 응고한 **`sobujang-briefing` 스킬**이

