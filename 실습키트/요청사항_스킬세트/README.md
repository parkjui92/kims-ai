# 요청사항 스킬세트 — 요청하신 5가지, 스킬로 만들어 왔습니다

> 사전에 보내주신 요청사항 5건을 각각 **참고용 스킬**로 응고한 세트입니다.
> 그대로 설치해도 동작하지만, 진짜 용도는 **뜯어보는 것**입니다 — 실습 5에서 배우는
> "내 판단 기준을 문서화하면 뭐든 스킬이 된다"의 실물 예시 5개이기도 합니다.
> 각 파일의 `▢ 조직 맞춤` 표시를 여러분 기준으로 바꾸는 순간부터 여러분의 스킬입니다.

## 요청사항 ↔ 스킬 매핑

| 요청 | 스킬 | 위치 |
|---|---|---|
| 1. 회의록 자동 작성 | `meeting-minutes` | `../심화A_회의록/skills/` (심화 A에서 실습) |
| 2. 동향 조사·기획보고서 | 정책연구팀 플러그인 (5인 팀) | 미니실습 ③에서 설치 |
| 2. └ 출처 검증·교차확인 | `fact-verify` | 이 폴더 `skills/` |
| 3. 소부장 브리핑 자동화 | `sobujang-briefing` | 이 폴더 `skills/` (심화 B의 응고본) |
| 4. JCR 미매칭 저널 조사 | `journal-tracer` | 이 폴더 `skills/` (심화 C의 응고본) |
| 4. └ 성과 시각화 | `html-dashboard` | 이 폴더 `skills/` (심화 D의 응고본) |
| 5. R&D·논문·특허 분석 | `rd-insight` | 이 폴더 `skills/` (분석 규율 프로토콜) |

## 설치 — 폴더 복사가 곧 설치

전부 설치:

```bash
cp -r 실습키트/요청사항_스킬세트/skills/* ~/.claude/skills/
```

하나만 골라 설치(예: 브리핑):

```bash
cp -r 실습키트/요청사항_스킬세트/skills/sobujang-briefing ~/.claude/skills/
```

(또는 Claude Code에 "이 폴더의 스킬들을 내 스킬 폴더에 설치해줘")

설치 후 Claude Code를 재시작하면, 해당 업무를 요청할 때 스킬이 자동으로 발동합니다.
확인: `이번 달 소부장 브리핑 만들어줘` 라고 말했을 때 스킬 규칙(원본 불변·검증표)이
작동하면 성공.

## 쓰기 전에 — 참고본을 내 것으로 만드는 3단계

1. **뜯어보기**: SKILL.md를 열어 어떤 규칙이 왜 있는지 읽는다 (전부 한 페이지 분량)
2. **맞추기**: `▢ 조직 맞춤` 표시(파일마다 2~3곳)를 여러분 실제 양식·분류·순서로 교체
3. **키우기**: 쓰다가 실수가 나오면 그 실수를 막는 규칙을 한 줄 추가 — 스킬은
   완성품이 아니라 **실수를 먹고 자라는 문서**입니다

## 보안 수칙

- 이 스킬들에는 **재료연 실데이터가 들어 있지 않습니다** — 규칙만 담겨 있습니다.
- 실데이터 적용은 사무실 보안 기준에 따라, 민감정보 제거본으로 진행하십시오.
- `journal-tracer`는 저널 정보만, `html-dashboard`는 개인정보 제거본만 받도록
  스킬 안에 이미 규칙이 박혀 있습니다.
- API 인증키는 `.env` 파일에 — 채팅창에 붙여넣지 않습니다.

## 출처·업데이트

  최신판은 저장소에서.
- 나머지 4종은 이 교육을 위해 만든 참고본 초판입니다. 개선판은 키트 업데이트
  채널(README 문의처)로 공지합니다.
