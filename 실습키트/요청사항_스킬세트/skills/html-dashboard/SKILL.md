# 파일 하나짜리 HTML 대시보드

집계 데이터를 받아 **자기완결 HTML 한 파일**로 시각화한다.
열기는 더블클릭, 공유는 파일 전달 — 받는 사람에게 아무 설치도 요구하지 않는다.

## 입력

- 집계 표 (엑셀 또는 CSV) — **개인정보 열 제거본만** 받는다. 성명·소속 상세 등이
  보이면 제거를 요청하고 진행을 멈춘다.
- 어떤 지표가 중요한지 사용자 지정이 없으면, 데이터를 보고 후보를 제안한 뒤 진행한다.

## 구성 (기본 4단)

```
① 핵심 지표 타일 4개   : 총량·증감 등 한눈 숫자 (지표 정의는 ▢1)
② 연도별 추이 차트     : 시계열이 있으면 필수
③ 분포 차트           : 분야별·유형별·기관별 등 (분류 체계는 ▢2)
④ 상세 표             : 차트의 근거 데이터 전체
```

## 기술 규칙 — 왜 "자기완결"인가

- **외부 라이브러리·CDN·인터넷 접속 0.** 차트는 인라인 SVG로, 스타일은 인라인
  CSS로 그린다. 이유: 기관 보안망(외부망 차단 PC)에서도 열려야 하고, 3년 뒤
  다시 열어도 CDN 소멸로 깨지는 일이 없어야 한다.
- 파일 하나로 완결한다. 이미지·데이터 파일을 따로 두지 않는다.
- 제목 옆에 **데이터 기준일**을 반드시 표기한다 — 대시보드는 "언제 기준 숫자인가"가
  생명이다. 기준일 없는 수치는 회의에서 반드시 질문받는다.

## 데이터 규칙

- 모든 수치는 입력 데이터에서 **계산해서** 넣는다. 어림값·기억값 금지.
- 타일의 합계와 상세 표의 합계가 일치해야 한다 (내부 정합).
- 데이터에 없는 항목을 채우지 않는다 — 빈 항목은 "해당 없음"으로 표시.

## 검증 절차 (산출 후 사용자에게 안내)

1. **오프라인 검증**: 인터넷을 끊거나 파일만 다른 PC로 옮겨 열어본다 — 그대로
   보이면 자기완결 성공.
2. **손 대조**: 차트 수치 중 3~4개를 골라 원본 집계와 대조할 수 있게, 대조용
   표(차트 값 ↔ 원본 셀 위치)를 함께 제시한다. 세는 것은 기계, 확인은 사람.
3. 합계 정합(타일 합 = 표 합)을 스스로 검산해 보고한다.

## 용도 분기

- 자문위원회·외부 배포: HTML (이 스킬의 기본 산출)
- 내부 실무 편집용: 엑셀 차트 삽입이 나을 수 있음 — 요청 목적을 확인하고 권한다.

## ▢ 조직 맞춤

- ▢1 타일 4개의 표준 지표 정의 (예: 과제 수·논문 수·특허 수·기술료)
- ▢2 분포 차트의 분류 체계 (예: 12대 기술분야)
- ▢3 기관 표준 색상·로고 (필요 시)
