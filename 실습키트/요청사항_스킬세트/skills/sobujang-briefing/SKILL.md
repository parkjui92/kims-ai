# 소부장 동향 브리핑 자동 조판

스크랩 엑셀(기사 목록)을 읽어 브리핑 문서 초안을 **생성**한다.

**제1원칙 — 문서를 고치지 않는다. 엑셀을 고치고, 문서를 다시 만든다.**
기사 1건이 빠지면 연번·목차·분류별 통계가 전부 연쇄로 바뀐다. 문서를 부분 수정하면
연번 밀림·목차 불일치·통계 누락이 반드시 생긴다. 항상 엑셀에서 전체를 재생성하면
이 오류들이 구조적으로 사라진다.

## 입력

- 스크랩 엑셀(`.xlsx`/`.xlsm`)의 기사 목록 시트 — 기본 시트명 `전체리스트` ▢1
- 필요한 열: 분류(정책/R&D/기업동향) · 기술분야 · 기관(부처) · 기사 제목 · 매체 · 날짜
  (열 이름이 다르면 데이터를 보고 대응시키되, 대응 결과를 먼저 보고하고 진행)
- **원본 엑셀은 절대 수정하지 않는다** — 읽기 전용. 수정이 필요하면 사용자에게
  엑셀 쪽을 고쳐 달라고 요청한 뒤 재생성한다.

## 출력 (md + 자기완결 HTML 동시)

```
# 소재부품장비 동향 브리핑 (초안) — [YYYY년 M월]

Ⅰ. 전체 기사 목차   : 표 | 연번 | 분류 | 제목 | 매체 | 날짜 |
Ⅱ. 정책 동향       : 기관별 절 구성 (과기정통부 → 산업부 → 중기부 → 기타) ▢2
Ⅲ. R&D·기업 동향   : 기술분야별 절 구성 (분야 목록·순서는 ▢3, 없으면 데이터 출현 순)
Ⅳ. 통계            : 분류별 건수·비율 표 + 분야별 건수·비율 표
```

- HTML은 외부 라이브러리·CDN 없이 파일 하나로 완결시킨다 (더블클릭으로 열람·메일 공유).
- HWPX가 필요하면 이 산출물을 변환 단계로 넘긴다 — 조판 스킬은 내용 배치까지만 책임진다.

## 처리 규칙

1. **연번·건수·비율은 항상 데이터에서 다시 센다.** 지난 호나 기존 문서의 숫자를
   이어받지 않는다 — 이월된 통계가 브리핑 오류의 최대 원인이다.
2. 기사 제목·매체·날짜는 엑셀 값을 그대로 옮긴다. 임의로 다듬지 않는다.
3. 분류·분야가 비었거나 애매한 행은 임의 배정하지 않는다 — 본문에서 빼지 말고
   **「분류 확인 필요」 절**에 따로 모아 행 번호와 함께 보고한다.
4. 요약문을 넣으라는 요청이 있을 때만 기사별 요약을 쓰되, 엑셀에 있는 정보
   (제목·비고 등) 범위 안에서만 쓴다. 기사 원문 내용을 지어내지 않는다.

## 검증 보고 (산출물 끝에 자동 첨부)

브리핑 마지막에 다음 검증표를 반드시 붙인다. 세는 것은 기계가, 확인은 사람이 한다.

| 검증 항목 | 엑셀 | 브리핑 | 일치 |
|---|---|---|---|
| 전체 기사 수 | N행 | N건 | ✅/❌ |
| 정책 / R&D / 기업동향 건수 | 각 건수 | 각 건수 | ✅/❌ |
| 분야별 건수 합 = 전체 | — | — | ✅/❌ |

하나라도 ❌면 원인을 보고하고, 산출물을 완성본이라 말하지 않는다.

## 갱신 요청을 받았을 때

"기사 하나 빼줘 / 분류 바꿔줘 / 최신으로 갱신해줘" → 문서를 고치지 말고:
1. 어느 행을 어떻게 바꿀지 확인 → 사용자가 엑셀(사본)을 수정
2. 같은 절차로 **전체 재생성** → 검증표로 변경 반영 확인

## ▢ 조직 맞춤 (설치 후 3곳을 여러분 기준으로)

- ▢1 시트명·열 이름: 실제 스크랩 엑셀의 구조로 교체
- ▢2 정책 기사 기관 순서: 조직 관행 순서로 고정
- ▢3 기술분야 목록·순서: 12대 기술 등 조직 분류 체계를 여기에 명시
