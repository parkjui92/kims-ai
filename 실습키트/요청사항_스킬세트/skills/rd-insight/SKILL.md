# R&D 데이터 → 정책 인사이트 분석 프로토콜

과제·투자·성과·논문·특허 데이터를 분석해 정책적 시사점으로 연결한다.
이 스킬의 정체는 계산기가 아니라 **분석 규율**이다 — 무결성을 먼저 보고,
고정 관점으로 빠짐없이 훑고, 사실과 해석을 분리한다.

## 0단계 — 데이터 무결성 점검 (분석보다 먼저, 생략 금지)

받은 데이터마다 확인하고 **점검표를 먼저 보고**한 뒤 분석에 들어간다:

- 행수·기간 범위 (몇 건, 몇 년~몇 년)
- 중복 (과제번호·논문 DOI 기준 — 다년도 과제의 연차 중복 여부 확인)
- 결측 (핵심 열의 빈 값 비율)
- 단위 (백만원/억원, 건수/편수 — 혼재하면 통일하고 보고)

이유: 무결성을 안 본 분석은 나중에 전부 재작업이 된다. 특히 다년도 과제 중복은
투자 총액을 조용히 부풀리는 최다 빈도 오류다.

## 1단계 — 과제·투자 데이터 분석 관점 (고정 체크리스트)

사업 간 비교·특징 도출은 아래 관점을 전부 훑고, 해당 없음도 "해당 없음"으로 남긴다:

| 관점 | 보는 것 |
|---|---|
| 투자 규모·추이 | 사업별 연도별 정부투자, 증감률 |
| 연구 분야 | 분야별 과제 수·투자 비중 ▢1 |
| 수행 주체 | 출연연 / 대학 / 기업(대·중소) 비중 |
| 지역 | 수행기관 소재지 분포 |
| 연구 단계 | 기초 / 응용 / 개발 비중 |
| 협력 구조 | 단독 vs 공동, 산학연 조합 |
| 성과 | 논문·특허·기술이전·기술료 (투입 대비) |

## 2단계 — 논문·특허 동향 (외부 데이터 연계)

- **OpenAlex** (인증키 불필요): `https://api.openalex.org/works?search=...&filter=...`
  — 주제별 연도 추이, 국가·기관 비교. 검색식을 결과에 기록한다(재현 가능성).
- NTIS·KIPRIS 등 키 필요 창구: 키는 `.env` 파일에 보관하고 채팅창에 붙여넣지 않는다.
- 단순 건수를 넘어서: **점유율·성장률을 병기**한다. "한국 100편"은 정보가 아니고
  "세계의 4%, 5년 새 2배"가 정보다.

## 3단계 — 공백·유망영역 판정 규칙

- 공백영역은 **교차 조건으로만** 판정한다. 예: "국내 투자 비중 낮음 × 해외 논문
  급성장" 또는 "논문 많음 × 특허·사업화 없음". 단일 지표(그냥 건수 적음)로
  공백이라 단정하지 않는다 — 투자가 적은 데는 이유가 있을 수 있다.
- 판정마다 근거 수치 2개 이상을 표로 병기한다.

## 4단계 — 사실/해석 분리 (이 스킬의 핵심 규율)

- 데이터에서 센 것 = 사실. 그 의미 부여 = 해석. **모든 시사점 문장에 [해석] 태그**를
  달고, 바로 옆에 근거 사실을 병기한다.
  - 예: `[해석] ○○ 분야는 기업 참여 확대 유인이 필요하다 (근거: 기업 비중 8%,
    전체 평균 31%)`
- 데이터에 없는 인과 주장 금지 — "투자가 늘어 논문이 늘었다"는 상관을 인과로
  바꾼 것이다. 쓰려면 "함께 증가했다"까지만.
- 확인 못 한 수치는 [출처 미확인] 표시하고 단정하지 않는다.

## 산출 양식

```
① 데이터 개요        : 출처·추출일·행수·기간·무결성 점검표
② 분석 결과          : 관점별 표·수치 (사실만)
③ [해석] 시사점       : 태그 + 근거 병기 (정책 제언은 여기서만)
④ 한계·추가 확인 필요  : 이 데이터로 말할 수 없는 것
```

④를 빼먹지 않는다 — 한계를 밝힌 분석이 회의에서 살아남는다.
