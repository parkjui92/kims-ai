# JCR 미매칭 저널 추적 조사

미매칭 저널 목록을 받아 저널별 변천 이력을 조사하고, **근거 URL이 붙은 매칭 후보 표**를
만든다. 매칭 하나가 과제 평가 점수를 바꾸므로, 이 스킬은 확정하지 않는다 —
사람이 확정할 수 있는 상태까지 조사를 끌어올리는 것이 목표다.

## 입력

- 미매칭 저널 목록 CSV — 열: 저널명 · ISSN · eISSN ▢1
- ⚠ **저널 정보만 받는다.** 과제·성과·연구자 정보가 섞인 파일이 오면 저널 열만
  분리해 쓰고, 나머지는 읽지 않는다고 보고한다 (내부 평가정보 반입 금지).

## 조사 절차 (저널 1건마다)

근거의 우선순위가 있다. 위에서부터 시도하고, 어느 단계에서 판정했는지 남긴다.

1. **Crossref journals API** (인증키 불필요): `https://api.crossref.org/journals/{ISSN}`
   — ISSN 유효성, 현재 등록 저널명, 최근 발행 실적
2. **ISSN Portal** (portal.issn.org) — ISSN·eISSN 공식 등록 정보, 개칭 이력
3. **발행사 공식 공지** — 개명·통합·이관 공지문 (가장 정확한 시점 근거)
4. 학술 DB·색인 서비스 — 보조 근거로만

조사 결과는 판정 7유형 중 하나로 분류한다:
**발행중 / 개명 / 통합 / 분리 / 폐간 / ISSN 변경 / 미확인**

## 결과표 (고정 양식)

| 원본 저널명 | ISSN | 판정 | 시점 | 현재 저널명 | 현재 ISSN | 근거 URL | 비고 |
|---|---|---|---|---|---|---|---|

- **모든 판정에 근거 URL을 붙인다.** URL을 못 붙이는 판정은 '미확인'으로 내린다.
- 시점(개명·폐간 연도)은 근거 문서에 명시된 것만 적는다.

## 판정 규율 (왜 이렇게 엄격한가)

- **확실하지 않으면 '미확인'.** 추정으로 채운 후보 하나가 잘못 확정되면
  평가 결과 전체의 신뢰가 무너진다. 미확인은 실패가 아니라 정직한 판정이다.
- 목록 전체가 '확실' 판정이면 오히려 의심하라 — 미매칭까지 온 저널들이
  전부 깔끔하게 확인될 확률은 낮다. 미확인 0건이면 근거 강도를 재점검한다.
- **JCR 등급·IF 수치는 이 스킬이 판정하지 않는다.** 그 수치는 기관이 구독하는
  원본 데이터로만 확인한다 — 웹에 떠도는 IF 추정치를 표에 넣지 않는다.

## 확정 절차 (사람 몫 — 결과표와 함께 안내)

1. 사람이 근거 URL을 **직접 열어** 확인한 뒤 확정 표시
2. 확정본만 기존 평가 파이프라인의 수기반영 단계에 입력 ▢2

## ▢ 조직 맞춤

- ▢1 입력 CSV의 실제 열 이름
- ▢2 파이프라인 반영 단계 이름·파일 경로 (예: 07_2 수기반영)
