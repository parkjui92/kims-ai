# 미니실습 ③ — 정책연구팀 플러그인: 팀을 들이고, 브리프를 맡긴다

> 목표: 5인 에이전트 팀을 설치하고, 4쪽 정책브리프를 킥오프한 뒤 **목차 승인 관문에서 개입**해 본다. 팀이 일하는 동안 심화 코스를 진행하고, 마지막에 수확한다.

## 1. 설치 — 명령 두 줄

Claude Code 안에서 그대로:
```
/plugin marketplace add parkjui92/policy-research-kit
/plugin install policy-research-kit@policy-research-kit
```
설치 후 Claude Code **재시작** → 확인:
```
방금 설치된 플러그인이 뭘 할 수 있는지 알려줘
```
다섯 팀원(설계·조사·집필·검수·변환)이 보이면 성공.

## 2. 킥오프 — 브리프 요청 (주제는 바꿔도 됩니다)

```
"첨단소재 공급망 재편이 국내 소재 R&D 정책에 주는 시사점" 주제로 4쪽 정책브리프 써줘
```

다른 주제 예시:
- `유럽 핵심원자재법(CRMA)이 국내 소재 산업에 주는 시사점`
- `AI 기반 소재 탐색(Materials Discovery) 동향과 정책 과제`

⚠ **공개 현안만** — 미공개 내부 이슈·자료는 넣지 않습니다.

## 3. 개입 — 목차 승인 관문 (이 실습의 목적)

몇 분 안에 목차 승인 요청이 옵니다. **그대로 승인하지 말고 반드시 한 번 고쳐 보세요**:
```
2장을 국내 현황 중심으로 바꿔줘
```
```
해외 사례는 일본·독일만 다뤄줘
```
```
제언은 3개로 압축하고, 재료연 역할을 한 줄 넣어줘
```

고쳐진 목차를 확인한 뒤 승인 → 팀이 조사·집필하는 동안 **심화 코스로 이동**.

## 4. 수확 — 확인 3종 세트

브리프가 완성되면:
1. **[보강 필요] 태그** 찾기 — 확인 못 한 숫자를 단정하지 않은 흔적
2. 조사노트의 **출처 URL 하나를 직접 열어보기** — 근거가 실재하는가
3. 검수보고서의 **지적사항 읽기** — 무엇이 걸러졌는가

> 과정 파일(연구설계·설계점검·조사노트·검수보고서)이 산출물과 함께 남습니다 — "이 숫자 어디서 왔나"에 파일로 답하는 구조.
