# 심화 D (선택) — 파일 하나짜리 성과 대시보드

> 목표: Power BI 없이, 자기완결 HTML 대시보드 한 장을 AI에게 만들게 한다. 열기는 더블클릭, 공유는 파일 전달.

## 0. 동봉된 예시부터

`샘플_성과대시보드.html` 더블클릭 — **가상 데이터**로 만든 예시입니다(실데이터 아님).
구성: 핵심 지표 타일 + 연도별 추이 + 분야별 분포 + 표. 외부 접속 없이 동작합니다.

## 1. 직접 만들기 (실습은 가상·공개 데이터로만)

집계 표(엑셀 또는 CSV — 개인정보 제거본)를 폴더에 두고:

```
이 집계 데이터로 자기완결 HTML 대시보드를 만들어줘.
구성: ① 핵심 지표 타일 4개 ② 연도별 추이 차트 ③ 분야별 분포 차트 ④ 상세 표.
외부 라이브러리·CDN 없이 인라인 SVG로 그리고, 파일 하나로 완결되게.
수치 옆에 데이터 기준일을 표시해줘.
```

## 2. 확인 포인트

- 인터넷 끊고 열어도 동작하는가 (자기완결 검증)
- 차트 수치가 원본 집계와 일치하는가 — **몇 개는 손으로 대조**
- 메일로 보내도 받는 사람이 더블클릭만으로 보는가

## 3. 실전 적용 시

- 자문위원회 배포용: HTML / 내부 실무용: 엑셀 차트 자동 삽입 — 용도로 선택
- 실데이터 사용 시 **개인정보 컬럼 제거본**(파이프라인 02단계 산출)만 사용

## 4. 가져가기 — 이 프롬프트가 스킬로

위 프롬프트의 규칙(자기완결 · 무CDN · 기준일 표기 · 손 대조 검증)을 응고한
**`html-dashboard` 스킬**이 `../요청사항_스킬세트/skills/`에 동봉되어 있습니다:

```bash
cp -r 실습키트/요청사항_스킬세트/skills/html-dashboard ~/.claude/skills/
```

이후 "이 데이터로 대시보드 만들어줘"만으로 같은 품질 규칙이 자동 적용됩니다.
