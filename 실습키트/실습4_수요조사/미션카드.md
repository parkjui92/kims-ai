# 실습 4 — 수요조사서 분류 · 클러스터링 (메인 핸즈온)

> **목표**: 수요조사서 40건을 ①기술분야로 분류하고 ②유사·중복을 묶고 ③회의에 올릴 요약표까지 한 번에.
> **소요**: 40분 (심화 포함 시 50분)
> **자료**: `수요조사서/` 40건(가상) · `핵심품목_리스트.csv` 18품목(가상)

⚠️ 이 폴더의 모든 자료는 **교육 실습용 가상 데이터**입니다. 실제 제안·기관과 무관합니다.
실제 업무 적용은 사무실에서 같은 절차로 진행하십시오(민감자료 반입 금지).

---

## 준비

1. Claude Code를 **이 폴더(`실습4_수요조사`)에서** 엽니다.
2. 첫 확인:
```
이 폴더 구조를 표로 보여줘
```
→ `수요조사서/` 40개 파일과 `핵심품목_리스트.csv`가 보이면 준비 끝.

---

## 4-1. 읽히고, 기술분야로 분류 (10분)

```
수요조사서 폴더의 파일을 전부 읽고, 각 건을 12대 기술분야 기준으로 분류해줘.
표로 정리하되 열은 연번 · 제안명 · 제안기관 · 기술분야 · 분류 근거(한 줄).
애매하면 임의로 정하지 말고 '분류보류'로 표시하고 이유를 적어.
결과는 01_분류표.md 로 저장해줘.
```

**✅ 성공 판정**
- 40행 표가 파일로 저장됐다
- **'분류보류'가 몇 건 있다** (0건이면 오히려 의심 — 애매한 걸 애매하다고 말했는지 확인)
- 분류 근거 열이 비어 있지 않다

**응용**: 우리 기관 분류 체계가 있으면 파일로 주고 `이 체계로 분류해줘`라고 하면 됩니다.

---

## 4-2. 유사·중복 클러스터링 (10분)

```
01_분류표.md를 기준으로, 내용이 유사하거나 중복되는 제안을 묶어줘.
· 묶음마다 클러스터명 · 포함 연번 · 공통 키워드 · 유사도 판단 근거를 적어라
· 기술분야가 달라도 해결하려는 문제가 같으면 같은 묶음으로 보고, 그 사실을 명시해라
· 애매한 경계는 '경계사례'로 따로 모아줘
결과는 02_클러스터.md 로 저장해줘.
```

**✅ 성공 판정**
- 클러스터 6~10개가 나온다
- 경계사례 목록이 따로 있다
- 각 묶음에 **판단 근거**가 붙어 있다

**관전 포인트**: "기술분야는 다른데 같은 문제를 푸는" 묶음이 나오면 성공입니다 —
분류표만 봐서는 안 보이던 중복입니다.

---

## 4-3. 클러스터별 요약표 (10분)

```
02_클러스터.md를 바탕으로 클러스터별 한 장짜리 요약표를 만들어줘.
열: 클러스터명 · 제안 건수 · 핵심 내용 3줄 · 주요 제안기관 · 검토 포인트
· 개조식 · 존댓말 없이 · 표 아래 총계 행
· 마지막에 [확인 필요] 항목을 따로 모아줘 (근거가 약하거나 판단이 갈린 것)
결과는 03_요약표.md 와 03_요약표.html 두 형식으로 저장해줘.
```

**✅ 성공 판정**
- md·HTML 두 파일이 생성됐다
- HTML을 더블클릭하면 브라우저에서 열린다
- [확인 필요] 목록이 있다

---

## 4-4. (심화) 핵심품목 매핑 (10분)

```
핵심품목_리스트.csv를 기준으로 앞의 40건을 매핑해줘.
· 각 제안이 어느 품목에 해당하는지, 근거 문구를 인용해서
· 해당 없음이면 '미해당' — 억지로 붙이지 마
· 품목별로 제안이 몰린 곳과 비어 있는 곳을 표로 보여줘
결과는 04_품목매핑.md 로 저장해줘.
```

**✅ 성공 판정**
- 품목×제안 매핑표 + **공백 품목** 목록이 나온다
- '미해당' 행이 존재한다 (전부 매핑됐으면 억지 매핑을 의심)

**왜 중요한가**: 수요조사가 "무엇이 들어왔나"에서
**"어디에 몰렸고 어디가 비어 있나"**라는 정책 판단 자료로 바뀝니다.

---

## 막혔을 때

| 증상 | 처방 |
|------|------|
| 파일을 못 읽는다 | 폴더 위치 확인 — `이 폴더 구조 보여줘`로 먼저 확인 |
| 40건 중 일부만 처리 | `전부 몇 건 읽었는지 세어서 보고해줘` — 누락 확인 후 이어서 |
| 결과가 화면에만 나온다 | `파일로 저장해줘`를 명시 (파일명까지 지정하면 확실) |
| 중간에 꼬였다 | `지금 상태 요약해줘` 후 이어가기 |

## 사무실에서 재현할 때

1. 실제 수요조사서를 **로컬 폴더**에 모읍니다 (채팅창에 올리지 않습니다)
2. 우리 기관 **분류 체계·핵심품목 리스트**를 기준 파일로 함께 둡니다
3. 위 프롬프트 4개를 순서대로 — 파일명만 바꾸면 그대로 동작합니다
4. **다음 달부터는 이 4개를 스킬 하나로** 묶으십시오 (실습 5의 방법 그대로)
