# 0_내작업폴더 — 오늘 실습의 홈

이 폴더에서 Claude Code를 열고 실습을 진행한다.
사무실로 돌아가서도 이 폴더를 그대로 복사해 쓰면 된다.

## 구조

```
0_내작업폴더/
├── README.md      ← 지금 읽는 문서
├── 자료/          ← 읽힐 자료를 여기에 (엑셀·한글·PDF)
└── 산출물/        ← AI가 만든 결과가 여기에 쌓인다
```

## 1부 · CLAUDE.md 만들기

이 폴더에서 Claude Code를 열고 아래를 붙여넣는다.

```
이 폴더용 CLAUDE.md를 5줄 이내로 만들어줘.
① 이 폴더가 무엇인지 ② 자료가 어디 있는지 ③ 하지 말아야 할 것
④ 결과물 형식 ⑤ 어떻게 검증하는지
일반론 말고, 나만 아는 것만 적어줘.
```

생성된 CLAUDE.md를 열어 **내 말로 고친다.** 예시:

- 이 폴더는 소재혁신선도본부 조사·기획 업무용이다
- 원본 자료는 `자료/`에 있고, 결과물은 `산출물/`에 만든다
- **원본 파일은 절대 수정하지 않는다** — 복사본으로 작업한다
- 결과물은 개조식·'~다' 종결 · 표에는 연번을 넣는다
- 수치를 집계하면 **원본 건수와 일치하는지 세어서 보고**한다

## 2부 · 실습 진행

각 실습 폴더의 `미션카드.md`에 프롬프트 전문이 있다.
자료를 이 폴더의 `자료/`로 복사해 두면 경로를 신경 쓰지 않아도 된다.

## 규칙

- 실습에는 **키트에 동봉된 자료와 공개 자료만** 사용한다
- 인증키는 채팅창에 붙여넣지 않는다 — `.env` 파일에 넣는다
- 미공개 과제·평가 자료, 개인정보 원자료는 반입하지 않는다
