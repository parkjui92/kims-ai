# 회의록 자동 작성 스킬

녹취록(.txt)과 개최안·회의자료를 읽고 아래 **7항목 회의록 초안**을 작성한다.
추정하지 않는다 — 녹취에 없는 내용은 쓰지 않는다.

## 입력

- 필수: 녹취록 텍스트 파일 (TIRRO 등 전사 도구의 내보내기)
- 권장: 개최안(안건 목록·참석자 명단) — 화자·안건 매핑 정확도가 올라간다
- 회의자료가 있으면 안건별 논의의 배경 참고로만 쓴다 (자료 내용을 발언처럼 쓰지 않는다)

## 출력 양식 (7항목)

```
# [회의명] 회의록 (초안)

1. 회의 개요        : 일시 / 장소 / 참석 (내부·외부 구분) / 작성일
2. 안건별 주요 논의  : 안건 단위로 발언 요지 재배열 (발언 순서가 아니라 안건 순서)
3. 참석자 의견      : 쟁점이 있었던 항목만 — 입장을 나란히 (누가·어떤 입장)
4. 결정사항        : 번호 붙여 한 줄씩. 합의 표현이 있는 것만
5. 미결사항        : 다음 논의로 넘어간 것 + 그 이유
6. 후속조치        : 표 | 조치사항 | 담당 | 기한 | — 3요소가 안 갖춰지면 [확인] 태그
7. [확인 필요]      : 사람이 봐야 할 곳 목록 (아래 태그 규칙에 걸린 전부)
```

## 판별 규칙

- **결정사항**: "~하기로 함 / 확정 / 승인 / 동의" 등 **합의 표현이 명시된 것만**.
  제안·검토 발언을 결정으로 승격하지 않는다.
- **미결사항**: 이견이 남았거나 "추후 논의 / 다시 보자"로 끝난 안건.
- **후속조치**: 행동 + 담당 + 기한 3요소. 빠진 요소는 `[확인: 기한 미지정]`처럼 태그.

## 금지 규칙 (위반 시 회의록으로서 실격)

- 녹취에 없는 내용을 만들어 쓰지 않는다 (추정 금지)
- 화자 불명 발언은 "참석자"로 표기하고 `[확인: 화자]` 태그
- 수치·날짜·고유명사·기관명은 들리는 대로 적고 `[확인]` 태그 — 전사 오류 가능성 상수
- 발언 요약은 **취지 보존** — 표현은 다듬되 입장을 바꾸지 않는다
- 민감해 보이는 발언(인사·평가·대외 관계)은 본문에 요약하되 `[확인: 수록 여부]` 태그

## 마무리 — 검수 체크리스트 (초안 끝에 자동 첨부)

```
□ 결정사항 문구를 녹취 원문과 대조했다
□ 후속조치의 담당·기한이 실제 지시와 일치한다
□ [확인] 태그를 전부 처리했다 (처리 전에는 '초안'을 뗄 수 없다)
□ 민감 발언의 수록 여부를 판단했다
```
