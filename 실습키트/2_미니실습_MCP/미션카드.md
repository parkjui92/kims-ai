# 미니실습 ② — MCP 두 개 설치: 한글 문서와 법령을 AI 손에

> 목표: kordoc(한글 문서 파싱)과 korean-law(법령 조회·인용 검증)를 설치하고 각각 한 번씩 실행해 본다.

## A. kordoc — .hwp/.hwpx/PDF를 AI가 읽게

1) 터미널에 한 줄 (Node.js 18+ 필요):
```bash
npx -y kordoc setup
```
2) 마법사에서 **Claude Code** 선택 → Claude Code **재시작**
3) 확인: 대화창에 `/mcp` → 목록에 kordoc이 보이면 성공
4) 첫 실행 (이 키트의 샘플로):
```
실습키트/심화A_회의록/sample_회의_개최안.hwpx 읽고 안건을 표로 정리해줘
```

**한계 미리 알기**: 구형 .hwp는 표·그림이 평탄화될 수 있습니다 — 원본 대조 원칙.

## B. korean-law — 법령이 대화 속으로

0) 키 준비: **open.law.go.kr** 회원가입 → OC(이메일 ID 앞부분) 발급 — 무료·즉시
1) Claude Code 안에서 두 줄 (설치 중 OC를 물어봅니다):
```
/plugin marketplace add chrisryugj/korean-law-mcp
/plugin install korean-law@korean-law-marketplace
```
2) 실행 예:
```
소재부품장비산업법에서 특화선도기업 지원 근거 조항 찾아줘
```
```
이 보고서 초안에 인용된 법령 조항이 전부 실재하는지 검증해줘
```

### 설치 오류 처방

`Permission denied (publickey)`가 뜨면 (SSH 미설정 PC의 알려진 증상) — 터미널에 한 줄 실행 후 재시도:
```bash
git config --global url."https://github.com/".insteadOf "git@github.com:"
```

## 오늘의 포인트

- MCP = AI에게 **도구를 쥐여주는 표준 규격** — 설치는 한 번, 이후는 자연어.
- korean-law의 **인용 검증**은 정책연구팀(미니실습 ③) 검수관의 '출처 실재 확인'과 같은 원리입니다.
