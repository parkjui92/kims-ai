## 구성

| 폴더 | 내용 | 예상 시간 |

| `2_미니실습_MCP/` | kordoc + korean-law MCP 설치 | 25분 |
| `3_미니실습_정책연구팀/` | 정책연구팀 플러그인 설치 + 4쪽 브리프 | 킥오프 15분 + 수확 |
| `심화A_회의록/` | 회의록 스킬 설치·수정·실행 (샘플 녹취 동봉) | 30분 |
| `심화B_브리핑자동화/` | 소부장 브리핑 자동 조판 (6월호 실물 산출 동봉) | 30분 |
| `심화C_JCR조사/` | JCR 미매칭 저널 조사 프로토콜 | 15분 |
| `심화D_대시보드/` | 성과 데이터 HTML 대시보드 (선택) | 15분 |
