# 미니실습 ① — 키 없이 5초, API 두 창구 붙여보기

> 목표: 발급 절차 전에 **"붙는다"는 감각**을 만든다. 아래 두 개는 인증키 없이 즉시 실데이터가 옵니다. (2026-08-05 실호출 확인)

## 1. 법제처 국가법령정보 — 소부장 법령 검색

터미널(또는 Claude Code 대화창에 "이거 실행해줘")에 그대로 붙여넣기:

```bash
curl -s "https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=law&type=XML&query=소재부품장비"
```

**확인할 것**: `resultCode 00` + 「소재·부품·장비산업 …특별조치법」 계열 3건 + 공포일자·소관부처.
→ 학습된 기억이 아니라 **오늘자 원천 데이터**라는 증거입니다.

## 2. OpenAlex — 전 세계 논문 검색

```bash
curl -s "https://api.openalex.org/works?search=solid state battery&filter=from_publication_date:2025-01-01&per-page=3"
```

**확인할 것**: `meta.count` (2만 건대) + 논문 제목·연도.

법제처 API로 소재부품장비산업법 현행 여부 확인하고, 공포일자 알려줘
```

```
