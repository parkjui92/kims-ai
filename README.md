# R&D 정책기획·조사분석 업무의 AI 에이전트 활용 실전

한국재료연구원 소재혁신선도본부 2차 교육 (2026. 08. 06.) 배포 자료입니다.
강의자료 · 참고자료 · 실습키트가 전부 이 폴더에 들어 있습니다.

두 HTML 모두 **자기완결 파일**입니다 — 내려받아 더블클릭하면 인터넷 없이도 열립니다.

## 실습 시작하는 법

1. 이 저장소를 통째로 내려받습니다 (`Code → Download ZIP`)
2. 압축을 풀고 **`실습키트/0_내작업폴더/`** 에서 Claude Code(데스크톱 앱)를 엽니다
3. 각 폴더의 **`미션카드.md`** 에 프롬프트가 순서대로 있습니다 — 복사해 붙여 넣으면 됩니다

터미널도 명령어도 필요 없습니다. 전부 **자연어**로 진행합니다.

## 자료에 관한 안내

- 실습에 쓰는 수요조사서·회의 녹취·브리핑 자료는 **전부 교육용 가상 데이터**입니다. 실제 기관·과제·인물과 무관합니다
- 실제 업무에 적용할 때는 **민감 자료를 채팅창에 올리지 말고 로컬 폴더**에 두고, 인증키는 `.env` 파일로 분리하십시오
- 미공개 과제·평가 원자료·개인정보 원본·인증키는 반입하지 않는 것이 원칙입니다
